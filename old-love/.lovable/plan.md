
# پلتفرم «مسیار» — نسخه اولیه حرفه‌ای (MVP فاز پایلوت)

بر اساس سند طرح، این نسخه اولیه یک اپلیکیشن وب راست‌چین فارسی است که فرآیند خرید ضایعات مس از پیمانکاران مخابرات را در سه پنل کاربری پیاده می‌کند: **فروشنده، کارشناس، ادمین**.

## دامنه فاز اول (MVP)

فقط جریان اصلی معامله + موتور قیمت‌گذاری زنده + کیف پول. مواردی مثل هوش مصنوعی خلوص‌سنجی، مزایده آنلاین، شبکه ذوب امین، لجستیک اسنپ‌مانند و Escrow پیشرفته در نقشه راه «توسعه آینده» می‌مانند (در UI به عنوان «به‌زودی» نشان داده می‌شود).

## ساختار صفحات

```
/                      صفحه فرود (معرفی مسیار + قیمت زنده مس)
/auth                  ورود / ثبت‌نام (فروشنده / کارشناس)
/seller                داشبورد فروشنده
  /seller/new          ثبت محموله جدید (نوع، وزن، خلوص، عکس، موقعیت)
  /seller/orders       سفارش‌های من + وضعیت (۶ حالت)
  /seller/orders/:id   جزئیات سفارش + تایید/رد قیمت نهایی
  /seller/wallet       کیف پول دیجیتال + تاریخچه تراکنش
/expert                داشبورد کارشناس
  /expert/queue        صف ارزیابی محموله‌ها
  /expert/orders/:id   ارزیابی، درخواست بازدید، ثبت قیمت نهایی
/admin                 داشبورد ادمین
  /admin/users         تایید کاربران و مدارک
  /admin/orders        مدیریت همه سفارش‌ها
  /admin/experts       تخصیص کارشناس
  /admin/pricing       تنظیم نرخ دلار، کارمزد، کسورات
  /admin/wallet        تسویه و گزارش مالی
```

## نقش‌ها و جریان سفارش

**۶ وضعیت سفارش:** `ثبت شد` ← `در انتظار کارشناسی` ← `قیمت نهایی اعلام شد` ← `تایید فروشنده / حمل` ← `توزین شد` ← `تسویه شد`

**فرمول قیمت‌گذاری زنده (نمایش لحظه‌ای در فرم ثبت):**
```
قیمت هر کیلو = (قیمت جهانی مس × نرخ دلار × درصد خلوص) − کسورات − کارمزد پلتفرم
```
در MVP: قیمت جهانی مس و نرخ دلار به صورت مقادیر قابل ویرایش در پنل ادمین ذخیره می‌شوند (بدون اتصال زنده به API بورس در فاز اول تا سادگی حفظ شود). ضریب خلوص، کسورات و کارمزد نیز از پنل ادمین قابل تنظیم است.

## طراحی بصری

- **راست‌چین (RTL) کامل، فونت Vazirmatn**
- پالت الهام‌گرفته از مس: قهوه‌ای مسی گرم `#B87333` به‌عنوان رنگ اصلی، پس‌زمینه کرم روشن، متن ذغالی، لهجه‌ای از فیروزه‌ای برای وضعیت‌های موفق
- کارت‌های تمیز، شفاف، اعداد بزرگ برای قیمت زنده و وزن
- آیکون‌ها: lucide-react
- تمام رنگ‌ها به صورت توکن‌های سمنتیک در `src/styles.css` (بدون هاردکد)

## بک‌اند (Lovable Cloud)

جداول:
- `profiles` (id, full_name, phone, role: seller/expert/admin, verified, national_id)
- `pricing_config` (copper_price_usd, usd_rate, fee_percent, deductions_percent) — تک‌ردیفه، فقط ادمین
- `shipments` (id, seller_id, scrap_type, estimated_weight, purity, photos[], location, status, estimated_price, final_price, expert_id, final_weight, created_at)
- `wallets` (user_id, balance)
- `transactions` (id, wallet_id, amount, type, shipment_id, created_at)
- Storage bucket: `shipment-photos`

RLS: فروشنده فقط رکوردهای خود، کارشناس فقط سفارش‌های تخصیص‌یافته، ادمین همه (از طریق جدول `user_roles` امن و تابع `has_role`).
احراز هویت: ایمیل/رمز عبور (شماره موبایل به صورت فیلد پروفایل).

## داده اولیه (Seed)

- یک کاربر ادمین نمونه
- یک ردیف `pricing_config` پیش‌فرض (مثلاً قیمت مس ۹.۵ دلار، دلار ۹۰,۰۰۰ تومان، کارمزد ۳٪)
- چند شغل نمونه از انواع ضایعات مس (کابل روکش‌دار، بار سوخته، مس براده، مس بدنه)

## بخش‌های خارج از دامنه (به «توسعه آینده» موکول)

هوش مصنوعی خلوص‌سنجی از عکس، سیستم مزایده، Escrow، شبکه ذوب امین، لجستیک زنده روی نقشه، چت داخلی، رتبه‌بندی، پیش‌خرید/فوروارد. در UI به صورت کارت‌های خاکستری «به‌زودی» در داشبورد ادمین دیده می‌شوند تا چشم‌انداز کامل حس شود.

## تحویل نهایی

اپلیکیشن اجرایی روی Preview با سه حساب نمونه (فروشنده / کارشناس / ادمین) و یک سفارش نمونه از ابتدا تا تسویه که همه وضعیت‌ها را پوشش می‌دهد.
