# آرشیو فایل‌های قدیمی (Lovable Legacy Archive)

این پوشه شامل فایل‌ها و تنظیمات قدیمی مربوط به پلتفرم Lovable و بک‌اند اولیه Supabase است که جهت نگهداری تاریخچه به این بخش منتقل شده است.
هر زمان که مایل بودید، می‌توانید کل این پوشه (`old-love`) را با خیال راحت حذف کنید؛ پروژه اصلی هیچ وابستگی به این فایل‌ها ندارد.

## محتویات این پوشه:
- `.lovable/` : فایل‌ها و متادیتای ویرایشگر اولیه Lovable
- `supabase/` : مایگریشن‌ها و تنظیمات قبلی Supabase پیش از مهاجرت کامل به Python FastAPI
- `AGENTS.md` : راهنمای ادیتور لاوبل
- `README-lovable.md` : مستندات اولیه ساخته‌شده توسط Lovable
